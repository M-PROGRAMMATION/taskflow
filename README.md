# TaskFlow

Application web de gestion de tâches en HTML, CSS et JavaScript natif, sans framework ni bibliothèque externe. Les données sont sauvegardées dans le navigateur avec `localStorage`.

## User Stories

1. En tant qu'utilisateur, je veux ajouter une tâche en renseignant son titre, sa priorité et sa date d'échéance afin de noter ce que j'ai à faire. Une tâche sans titre est refusée.
2. En tant qu'utilisateur, je veux voir la liste de toutes mes tâches avec leur titre, leur priorité, leur échéance et leur statut afin d'avoir une vue d'ensemble de mon travail.
3. En tant qu'utilisateur, je veux modifier le titre, la description, la priorité ou l'échéance d'une tâche existante afin de corriger une erreur ou de tenir compte d'un changement.
4. En tant qu'utilisateur, je veux marquer une tâche comme terminée afin de voir clairement ce que j'ai déjà accompli. Une tâche terminée apparaît barrée.
5. En tant qu'utilisateur, je veux supprimer une tâche afin de retirer de ma liste celles qui ne sont plus utiles.
6. En tant qu'utilisateur, je veux retrouver mes tâches après avoir fermé puis rouvert mon navigateur afin de ne pas perdre mon travail.
7. En tant qu'utilisateur, je veux filtrer mes tâches par statut (toutes, à faire, terminées) afin de me concentrer sur ce qui reste à faire.
8. En tant qu'utilisateur, je veux trier mes tâches par priorité ou par date d'échéance afin de savoir quoi faire en premier.

### Fonctionnalités complémentaires (recommandées, hors user stories principales)

- **Recherche par mot-clé** : en tant qu'utilisateur, je veux rechercher une tâche par un mot de son titre ou de sa description afin de la retrouver rapidement quand la liste est longue.
